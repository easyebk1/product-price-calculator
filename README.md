# Υπολογιστής Τιμής Πώλησης

Μια απλή, responsive web εφαρμογή που υπολογίζει την τιμή πώλησης ενός προϊόντος με βάση την καθαρή τιμή αγοράς, το ποσοστό κέρδους και τον ΦΠΑ.

## Υπολογισμός

- Κέρδος = καθαρή τιμή αγοράς × ποσοστό κέρδους
- Τιμή πώλησης χωρίς ΦΠΑ = καθαρή τιμή αγοράς + κέρδος
- ΦΠΑ = τιμή πώλησης χωρίς ΦΠΑ × ποσοστό ΦΠΑ
- Τελική τιμή = τιμή πώλησης χωρίς ΦΠΑ + ΦΠΑ

Οι προεπιλεγμένες τιμές είναι 20% κέρδος και 24% ΦΠΑ. Τα αποτελέσματα ενημερώνονται καθώς πληκτρολογείς και δεν αποθηκεύονται.

## Εκτέλεση τοπικά

Απαιτείται Node.js.

```bash
npm install
npm run dev
```

Για έλεγχο παραγωγικής έκδοσης:

```bash
npm run build
npm run preview
```
